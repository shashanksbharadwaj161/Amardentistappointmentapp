## Review standard

Screens are reviewed at phone and desktop widths for hierarchy, clipping, overflow, touch targets, accessible labels, English/Bangla expansion, error/empty states, and honest safety language. Provider-dependent controls remain visibly marked as configuration or pilot gates until their real credentials are supplied.
